Admin FAQ

Quick answers.

Is the admin panel extra?

No. It's included with every website, on both the $199/month and $1,499 plans.

What if I break something?

You can't break the design from the admin panel — you edit content, not code. And with regular backups, we can restore an earlier version.

If I leave, do I keep my leads?

Yes. Every lead is emailed to you as it comes in, and we'll export the full list for you on request.
